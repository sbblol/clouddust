# CloudDust Prompt Library

This folder contains reusable AI prompts designed to assist in writing, expanding, or ideating blog content for CloudDust.

### 📦 Structure

- `prompt-write-from-vocab.md`: Use an existing vocabulary concept to generate a blog post
- `prompt-suggest-new-post.md`: Suggest a new post based on metaphor combinations
- `prompt-structure-template.md`: General post structure scaffold
- `README.md`: This file

---

## 🧠 Purpose

These prompts are designed to be used with:

- ChatGPT / Copilot
- Custom prompt-injection tools
- Future integrations inside `post-builder.html`
