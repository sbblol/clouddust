# CloudDust Vocabulary

This folder contains the **conceptual vocabulary** of CloudDust — a growing set of analogies, visual metaphors, and symbolic terms used to express complex cloud security ideas in simple, familiar ways.

### 🎯 Purpose

CloudDust Vocabulary is not just for fun — it's a tool for:

- Making abstract technical ideas more accessible
- Enabling better storytelling and engagement
- Reinforcing consistent themes across posts
- Embedding subtle messages and tone
- Supporting future interactive elements (like filters or tag-based navigation)

### 📦 Structure

- `dust.json`: A flat list of vocabulary entries.
  Each entry includes:
  - `category`: Concept type (e.g., "Dust Type", "Action Tool", "Experience")
  - `concept`: The object or idea (e.g., "Vacuum Cleaner")
  - `icon`: Emoji representation
  - `message`: Short metaphorical meaning

> Future expansion may include additional fields like `tone`, `postUsage`, `reaction`, or `humor`.

### 🛠️ Usage in Posts

Start by manually embedding key concepts as Markdown tables or reference blocks.  
Later, you can build a dynamic interface that loads the JSON and renders it as an interactive glossary.

### 🔮 Future Ideas

- Humor mode: A toggle that adds quirky interpretations
- Filters by category or mood
- Internal linking to related blog posts
- Vocabulary injection into posts by tag

This vocabulary will grow over time — just like the dust.
